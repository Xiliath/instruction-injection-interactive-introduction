🔍 Hoe werkt de Instruction Injection?

Op deze pagina is een verborgen script actief dat:

  • Formulierdata onderschept voordat deze wordt verzonden
  • Extra informatie verzamelt (browser, tijdstempel, pagina-informatie)
  • Data naar een externe API stuurt via /api/collect
  • Dit gebeurt onzichtbaar voor de gebruiker

In een echte aanval: De geïnjecteerde instructies kunnen AI-systemen manipuleren om gevoelige informatie te lekken, ongewenst gedrag te vertonen, of beveiligingsmaatregelen te omzeilen.
